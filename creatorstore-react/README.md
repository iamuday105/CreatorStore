# CreatorStore React UI

## Start
1. Install Node.js 18+
2. `npm install`
3. `npm run dev`
4. Open the URL shown by Vite (normally http://localhost:5173)

Backend expected at `http://localhost:8080/api`.

## Routes
- `/` Customer store
- `/cart`
- `/checkout`
- `/admin/dashboard`
- `/admin/products`
- `/admin/orders`

## Backend note
Enable CORS for `http://localhost:5173`.
